# Publishing Format Reference

Canonical prose should be stored in the future story/chapter structure once writing begins.

Publication exports are derived copies, never a second canon source.

Recommended chapter formatting:
- clear chapter title;
- mobile-readable paragraphs;
- `◆ ◆ ◆` for deliberate scene breaks;
- System messages on separate lines or blocks;
- no internal author planning notes in published prose;
- no routine `Open Questions` sections at chapter ends.

Do not create publication exports before actual chapter prose exists.
