# Chapter Template

> Neutral drafting/recheck template. New numbered prose requires the parent project authority, target arc plan, and inherited entry state.

## Mandatory Context Gate

Before drafting or revising this chapter:
1. follow `../00_PROJECT/PRODUCTION_AND_RECHECK_PROTOCOL.md`;
2. complete `CONTEXT_RECEIPT_TEMPLATE.md`;
3. load the task-appropriate parent authority;
4. read the previous chapter;
5. read the target chapter in full for recheck/revision tasks;
6. read the next chapter or next planned state when available;
7. establish the inherited entry state before writing.

**NEW_CHAPTER requires a target arc plan.** Do not create new numbered prose without it.

For an already published/locked manuscript, a **locked recheck/revision fallback** is allowed when no standalone arc plan exists: load the final/current master story plan, canonical locked manuscript target range, surrounding chapters, progression/Evolution authority, applicable QA/revision ledger, and relevant story-memory/character/world authority. Do not create a retroactive arc plan merely to satisfy this template.

Required result: `GO` or `PARTIAL GO — unaffected scope only`.

If a required fact is missing, record `UNKNOWN / NOT ESTABLISHED`. If equal-authority sources conflict, record `CONTRADICTION — AUTHOR DECISION REQUIRED`. Do not guess, silently merge, or invent a bridge event.
