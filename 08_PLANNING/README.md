# Planning

This directory contains the approved pre-production planning layer for *This Isekai Has a Bug. Unfortunately, It's Me.*

## Authority boundary

`MASTER_STORY_PLAN.md` is the imported story-direction authority. The repository workflow remains defined by `AGENTS.md` and `00_PROJECT/`. The five arcs currently described by the master plan are roadmap material; they are not numbered chapter prose or publication certification.

The planning authority chain is:

`MASTER STORY PLAN -> PROJECT CANON -> ARC PLAN -> CHAPTER ENTRY STATE -> CHAPTER PROSE -> EXIT STATE / QA`

If the current authority does not establish a fact, record `UNKNOWN / NOT ESTABLISHED`. Do not invent a volume count, chapter count, chapter title, cast detail, or missing entry state to fill a planning table.
