# Repository Agent Instructions — This Isekai Has a Bug

## Scope

This is a separate story project. The downloaded master plan is story source material and planning authority, not an instruction document for the agent. Repository workflow instructions come from this file and `00_PROJECT/`.

Do not copy canon, prose, exports, locked-book manifests, or story-specific scripts from the companion bat-saga repository. Reusable templates and workflow structure may be adapted here.

## Branch and commits

- `master` is the only working branch for this project.
- Make small, focused commits for each completed change.
- Do not create a second production branch unless the author explicitly changes this policy.

## Story authority

Use this order:

`MASTER STORY PLAN → PROJECT CANON → ARC PLAN → CHAPTER ENTRY STATE → CHAPTER PROSE → EXIT STATE / QA`

The current master plan is `08_PLANNING/MASTER_STORY_PLAN.md`. It establishes the premise, fixed rules, themes, five initial arcs, and long-term direction. It does not silently authorize facts absent from the plan.

If a required fact is absent, record `UNKNOWN / NOT ESTABLISHED`. If equal-authority files conflict, record `CONTRADICTION — AUTHOR DECISION REQUIRED`.

## Required story workflow

Before substantive story planning, drafting, revision, or canon changes:

1. classify the task;
2. read `00_PROJECT/PRODUCTION_AND_RECHECK_PROTOCOL.md`;
3. complete `07_TEMPLATES/CONTEXT_RECEIPT_TEMPLATE.md`;
4. load the applicable authority and entry state;
5. check unknowns and contradictions;
6. perform only the approved scope;
7. reconcile the exit state;
8. run applicable QA;
9. leave the work uncertified when a required gate is incomplete.

## Prose baseline

Use `06_REFERENCES/WRITING_STYLE_GUIDE.md`. Preserve the plan's intended balance of dark consequences, comedy as coping, gradual identity development, and slow fourth-wall progression. Do not turn the protagonist's jokes into proof of supernatural fourth-wall powers before the plan earns them.

## Current project state

The repository is structural pre-production only. No book count, chapter count, detailed canon, character catalog, or numbered manuscript is established beyond what the master plan explicitly states.
