# Story Memory

The ledgers in this directory track continuity across arcs and chapters. They are derivative planning memory and cannot outrank the master plan, approved canon, or canonized prose.

- `MYSTERY_LEDGER.md` contains unresolved reader questions with `OPEN` or later evidence-based states.
- `FORESHADOWING_LEDGER.md` contains planned seeds with `PLANNED` or later evidence-based states.
- A planned record is not canonized prose.
- A seed is not `PLANTED` until approved prose contains it.
- A payoff requires prior setup, exact chapter references, reader/character knowledge reconciliation, and durable consequences.
- Do not invent an answer, character knowledge, or future power to make a ledger entry complete.
